# Mason

**Mason** is a Revit plugin designed to make repetitive tasks effortless.
Most tools are **one-click** to run, dramatically speeding up workflows, and the system is built to be **easy to extend** with new command tools.

---

## Key Features

- 🖱 **One-click operations** — Automate complex Revit actions in a single click.
- 🧩 **Extensible architecture** — Add new tools and commands without hassle.
- ⚡ **Productivity-focused** — Reduce time spent on repetitive modeling tasks.
